# Student Registration Form

A simple beginner-level student registration form made with HTML and CSS.

## Files
- `index.html` — contains the form structure and fields.
- `style.css` — contains the design and layout.

## How to run
1. Download or clone this project.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser.
4. You can check directly on browser link is given in the discription.

## Note
This is a front-end practice project. The form does not save or send submitted information because it does not have a backend.
